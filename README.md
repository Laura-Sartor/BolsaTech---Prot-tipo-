🎓 BolsaTech

⚙️Sobre o projeto:
O BolsaTech é um protótipo de uma plataforma web desenvolvido para fins acadêmicos, com o objetivo de facilitar o processo de inscrição em bolsas de estudo, auxiliando estudantes na organização de documentos e no acompanhamento de prazos e inscrições.

💻Funcionalidades:
- Busca de instituições e editais.
- Checklist de documentos obrigatórios e opcionais.
- Validação de arquivos enviados.
- Identificação de documentos pendentes.
- União de arquivos PDF.
- Assistente de IA para dúvidas sobre documentos.
- Acompanhamento de inscrições e geração de protocolo.

⚠️Observação:
Este projeto é um protótipo acadêmico. As instituições, os editais e as respostas apresentados são fictícios. A autenticação e o armazenamento de dados são simulados/localizados no navegador.
